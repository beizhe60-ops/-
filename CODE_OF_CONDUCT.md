# Code of Conduct

## Our standard

We want this project to be useful, respectful, and safe for contributors of different backgrounds and experience levels.

Examples of positive behavior:

- Being respectful in feedback and discussion
- Assuming good intent while staying honest about problems
- Sharing context that helps others reproduce, understand, and fix issues

Examples of unacceptable behavior:

- Harassment, discrimination, or intimidation
- Publishing someone else's private information without permission
- Abusive language, threats, or personal attacks

## Scope

This code of conduct applies to project discussions, issues, pull requests, and other community spaces connected to this repository.

## Enforcement

Project maintainers may remove comments, close discussions, or block participation for behavior that harms the community or disrupts collaboration.
