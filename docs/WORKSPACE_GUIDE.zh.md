# 工作台使用说明

登录后台后，先在「账号管理」登录 Telegram 账号，再选择要使用的功能。

## 群发任务

1. 点击「新建群发」，填写名称、发送账号和文字通知。
2. 点击「更新群组列表」，搜索并勾选接收群；列表中缺失的群可在高级设置填写完整 ID。
3. 选择启动后发送或指定北京时间，保存草稿并检查预览。
4. 点击「确认启动群发」。服务处于运行状态时才会发送。

每个任务发送一轮，记录中逐群显示成功、等待、失败或待核实。暂停后可继续，取消只取消尚未发送的内容。待核实结果应先检查接收群，不要直接复制任务重发。当前支持文字通知；不包含循环群发、图片或附件编辑。

## 监测转发

选来源群、填写关键词，再选转发目标群。保存后处于暂停状态，核对后启用。私信账号的接收绑定和文案继续在「账号管理」配置，转发和私信结果在「转发与私信记录」查看。

## AI 群组分析

1. 选择监测账号与需要分析的群，无需关键词。
2. 设置每日定时、累计新增条数或仅手动生成。设置每次分析条数上限及最近多少小时的范围。
3. 选择摘要发送到群组或私人账号。
4. 展开「AI 连接设置」，填写完整接口地址、准确模型 ID 和对应服务商 API Key，点击「测试 AI 连接」。
5. 保存摘要设置后先「预览摘要」；需要推送时点击「立即生成并推送」，或启用自动摘要。

账号需要加入来源群，接收端需要允许该账号发消息。只分析服务启动后实际收集到的文本；首次设置后没有消息时需等待群内新发言。预览和立即推送均使用已保存设置，连接测试使用当前填写的连接参数。AI 连接测试与预览会消耗服务商额度。

HTTP 401/403 表示凭据或访问权限问题；HTTP 503 表示 AI 服务暂不可用，应检查服务商模型渠道。运行记录区保留最近的预览、推送成功、失败和待核实结果；服务健康不等于 AI 服务商可用。

## 退出账号与删除任务

- 「账号管理 → 退出账号」只退出该 Telegram 账号。平台保持运行，其他账号不受影响。该账号的任务配置保留，重新登录后继续按原设置运行。
- 每条监测绑定旁的「删除任务」会移除该绑定，取消尚未发送的内容。历史记录保留，已经发起或发送的消息不撤回。
- 左下角管理员的退出按钮只退出网页后台，后台任务继续运行。

## 私信图片、表情与文字链接

1. 打开「账号管理 → 私信账号 → 接收群组与私信文案」。
2. 输入文案，直接输入表情或点击常用表情。选中文字后点击加粗、斜体或下划线。
3. 点击「文字链接」，填写显示文字和完整网址，再点击「插入链接」。
4. 按需上传一张 JPG、PNG 或静态 WebP 图片（最大 5 MB）；图片会与文字一起发送。
5. 点击「预览图文（不发送）」检查，最后保存接收绑定。

带图片的文案最多 1024 字符，纯文字最多 3500 字符；表情可能占两个字符，用户名替换需要预留长度。个人账号支持可点击的文字链接；消息底部的独立链接按钮属于机器人功能。当前不含自定义 Premium 表情、动图、多图或视频。

旧任务如果单独填写过私信文案，该文案仍优先使用；清空旧任务文案后才使用账号的新图文。更换文案或配图会取消该账号受影响的待发送私信，后续新消息使用新设置。移除配图后保存才生效，历史素材保留。
