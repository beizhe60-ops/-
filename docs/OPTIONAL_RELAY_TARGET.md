# 转发目标允许暂时留空

- 网页空目标提交 null；API 允许省略或 null，非空值仍执行完整群 ID 校验。
- 新绑定仍默认暂停，空目标不能启用；编辑清空目标仍暂停并取消旧待发送消息。
- 消息接收、入队和发送均检查未配置目标，不采用其他绑定的目标或示例 ID。
- 旧群目标保持原值；旧私信绑定迁移忽略未配置目标。

## 数据兼容与发布

relay_tasks.relay_chat 改为可空。启动时在取得单进程锁后，通过可重复执行的升级调整旧表。SQLite 在事务内重建表并检查外键，保留旧记录、索引及关联，失败回滚；新数据库直接创建可空字段。其他数据库使用 Alembic 对应 ALTER 操作，目前仅验证 SQLite。

发布前应停止本服务并一致性备份数据库及配套加密配置；不涉及其他机器人。回退应恢复发布前数据库及代码，不能直接让旧代码读取含空目标的新记录。此轮仅修改本地代码，未升级生产数据库或发布服务器。

## 验证

53 项自动测试通过（仍有既有弃用警告）；覆盖空值保存、禁止启用、补填启用、再次清空、无目标不入队不发送，以及旧表升级的关联完整性与重复执行。

Headless Chrome 使用模拟 API 检查：留空提交 null、保存后“待配置”、重新编辑仍为空、390px 窄屏表单无横向溢出。未向 Telegram 发消息，未进行真实 Telegram 联调。
