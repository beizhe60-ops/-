# 频道采编使用说明

从左侧进入“频道采编”，点击“新建采集”。

1. 选择已登录的采集账号，来源填写 `https://t.me/qt00`。
2. 排除词默认“七天”，命中正文或图片说明就整帖过滤。广告规则可逐行增加、删除，使用“测试筛选”核对，不会发送消息。来源频道名称不参与匹配。
3. 保存后点“验证并启用”。后台记录此刻最新消息，只收集其后的新帖；暂停后再启用同样重新建立起点。可以先不填自己的发布频道。
4. 在“待编辑”中打开帖子，左边核对原文及附件，右边编辑正文、链接、表情和文字样式。保存草稿后可关闭网页，下次继续编辑。
5. 在采集设置填写自己的曝光频道完整负数 ID，并授予采集账号该频道的发布消息权限。保存设置会暂停采集，可重新启用。
6. 编辑完成，点“确认发布”并核对目标 ID。发布状态在“待发布 / 发布中”“已发布”“发布失败”“结果待核实”中查看。待开始的发布可以取消；结果待核实请先查看真实频道，避免重复发出。

图片、视频、文件和相册可随正文复制发布；也可取消“保留原附件”。带附件正文最多 1024 个 UTF-16 单位，纯文字最多 4096 个，部分表情占两位。超长正文会保留编辑内容并提示精简。原附件引用由 Telegram 提供，不是永久本地备份；原帖删除或账号权限变化会影响附件读取。

广告过滤基于文字规则。图片中的文字、无明确标记的广告和真假曝光判断，需要编辑者在草稿阶段核对。被过滤的记录可切换到“已过滤”查看，默认不进入发布流程。已有草稿不会随新规则重新分类。

每个来源通常约 15 秒核对一次，受账号数量、网络、共享账号操作和 Telegram 等待影响可能更慢。正常采集仅在源频道有新内容后产生草稿；没有新内容时列表保持不变。频道采编、群发、AI 分析和关键词转发分别配置；右上角“暂停全部”停止全部后台模块。
