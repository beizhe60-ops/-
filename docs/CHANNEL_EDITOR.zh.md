# 频道采编使用说明

默认流程：读取来源新帖 → 过滤关键词和广告 → 自动套用档案模板 → 发布到自己的频道。

1. 左侧进入“频道采编”，新建或打开“采集设置”。选择已登录账号，来源可填写 `https://t.me/qt00`。
2. 排除词默认“七天”，正文或图片说明中命中就整帖过滤；广告规则逐行设置。可以粘贴原帖，使用“测试筛选”和“预览自动排版”，两个按钮都不会发送消息。
3. 发布方式选择“全自动排版并发布”。模板标题可设为自己的频道品牌，例如“曝光档案”。标题不带编号；表情风格可选警示、醒目、简洁，事件正文可选普通、加粗、斜体、下划线、删除线、引用、等宽、剧透。
4. 在“你的发布频道 ID”填写自己频道的完整负数 ID，授予同一账号该频道的发布消息权限。可以先留空；留空时只自动排版并保留为草稿。
5. 保存后点击“验证并启用”。有目标的全自动模式会检查目标频道权限。从此刻起，新帖筛选通过就自动发布，无需逐条点确认。每次重新启用都从当前最新位置开始，旧草稿不会批量补发。
6. “全部状态”查看最新结果；“已过滤”查看命中原因；“待发布 / 发布中”查看队列；“已发布”查看成功记录；失败和结果待核实单独查看。暂停来源会停止后续采集并把尚未开始的自动发布留回草稿。

## 自动排版

发布正文不再附加分隔线、附件说明或原帖链接。后台列表和草稿仍可打开原帖，事件正文中原有的链接照常保留。

模板保留原帖事件叙述，整理明确的名称、用户名、ID、金额、交易时间和地址，移除资料区中的国籍与同步时间。未提供的字段隐藏，未识别内容留在正文；不会从多个叙述金额中猜测损失总额，也不调用 AI 改写事实。

图片、视频、文件与相册仍随帖子发布。带附件正文超过 1024 个 UTF-16 单元时先发附件，再发送完整排版正文；纯文字分段上限 4096 单元，表情按实际长度处理。长文和相册发布中出现部分成功或超时，请核对频道中的已送达内容，系统不会盲目整帖重发。

## 人工模式与旧草稿

选择“人工编辑确认发布”时，新帖进入待编辑草稿。可选中文字使用工具栏设置加粗、斜体、下划线、删除线、引用、等宽、剧透、链接，插入表情或日期文字；“纯文本”清除选中文字格式。剧透预览可点击展开。可编辑正文、链接和文字样式，或使用“套用自动模板”重新生成并保存排版，之后手动确认发布。切换到全自动仅影响新帖，不自动发送旧草稿。配置修改后需要重新启用来源。

广告过滤依据文字规则，不做图片 OCR 或视频分析。原附件保存为 Telegram 引用，非永久本地备份；原帖删除或权限变化可能导致附件不可读。来源通常约 15 秒核对一次，受网络、共享账号操作和平台等待影响可能更慢。右上角“暂停全部”停止包括频道采编在内的全部后台模块。

先预览测试：打开“采集设置”，选择风格与正文样式，展开“用一段文字测试筛选与排版”，粘贴原帖后点“预览自动排版”。预览不会保存设置或向频道发消息；满意后再保存设置并“验证并启用”。
